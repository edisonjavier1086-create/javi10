README - Mini-sitio Cúbica

Instrucciones rápidas para probar y verificar (macOS / cualquier SO con navegador):

1) Abrir localmente
- Abre `index.html` en tu navegador (doble clic o arrastrar al navegador).

2) Qué verificar visualmente (lista rápida):
- La hoja `estilos.css` está aplicada (cambios de tipografía, fondo y colores).
- Header sticky y menú con submenú funcionan al pasar el mouse.
- Formularios: completa y envía el formulario en la sección "Servicios y Solicitud" — el JSON resultante aparece en `#resultadoSolicitud`.
- Inputs HTML5: prueba `email`, `number`, `date`, `datalist`.
- Float/clearfix: ver bloque flotante junto al contenido.
- Flexbox: la sección "Maquetación con Flexbox" debe mostrar columna principal más ancha y una lateral.
- Multimedia: en [recursos.html](recursos.html) confirma que el `video`, `audio` y `iframe` cargan.
- Posicionamiento: existe un banner fijo (abajo a la derecha) y elementos sticky.

3) Comprobaciones funcionales (opcionalmente en consola devtools):
- Revisar la consola para el objeto JSON impreso al enviar el formulario.
- Verificar que `javascript-basico.js` está cargado (buscar en Network o consola).

4) Cambios rápidos que puedo hacer por ti
- Ajustar tamaños de imagen, espaciados o colores.
- Añadir validaciones adicionales al formulario (JS).
- Generar un pequeño zip listo para subir.

Si quieres, pruebo ajustes específicos ahora (¿qué prefieres: colores, espaciado, o validar y sanitizar el formulario?).
